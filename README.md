# Свадебное приглашение — установка

Стек: статика (HTML + CSS + ванильный JS, без сборки) на GitHub Pages, приём ответов — Google Apps Script (runtime V8) → Google Таблица. Всё в бесплатных лимитах.

Файлы:

```
index.html      страница
styles.css      стили
app.js          настройки + логика
apps-script.gs  код для Google Apps Script (в репозиторий класть не обязательно)
audio/          сюда положить трек, например wedding-song.m4a
```

---

## 1. Заполнить данные

Всё в начале `app.js`, блок `CONFIG`:

```js
groom, bride        имена
date                { year, month, day, hour, minute } — месяц 1–12
utcOffset           '+06:00' для Кыргызстана (постоянный, без перевода часов)
addressLines        строки адреса
mapUrl              ссылка на 2GIS или Google Maps
audioSrc            путь к аудио; пустая строка — кнопка музыки не появится
rsvpUrl             заполняется на шаге 4
maxGuests           максимум гостей в счётчике
```

Тексты на странице — прямо в `index.html`, служебные фразы — в объекте `TEXT` в `app.js`.

## 2. Таблица для ответов

Создать пустую Google Таблицу. ID — кусок URL между `/d/` и `/edit`:

```
https://docs.google.com/spreadsheets/d/ЭТОТ_КУСОК_И_ЕСТЬ_ID/edit
```

## 3. Скрипт

1. https://script.google.com → **Новый проект**.
2. Вставить содержимое `apps-script.gs` вместо кода по умолчанию.
3. В строке `SHEET_ID` подставить ID из шага 2. Лист `RSVP` и заголовки создадутся сами.
4. Сохранить.

## 4. Публикация скрипта

**Начать развёртывание → Новое развёртывание → тип: Веб-приложение**:

- Запуск от имени: **Я**
- У кого есть доступ: **Все** (обязательно, иначе браузер гостя получит отказ)

Разрешить доступ к аккаунту при первом запуске. Скопировать URL вида
`https://script.google.com/macros/s/.../exec` и вставить в `CONFIG.rsvpUrl`.

Проверка: открыть этот URL в браузере — должно вернуться `{"ok":true,"service":"rsvp"}`.

Важно: после любой правки кода нужно **Управление развёртываниями → изменить версию на «Новая»**, иначе сайт продолжит работать со старым кодом.

## 5. GitHub Pages

1. Новый публичный репозиторий, например `toy-azamat-aiperi`.
2. Загрузить файлы (`index.html` — в корне репозитория, не в подпапке).
3. **Settings → Pages → Source: Deploy from a branch → main / (root)**.
4. Через 1–2 минуты сайт откроется по адресу `https://ЛОГИН.github.io/ИМЯ-РЕПО/`.

## 6. Проверить

Отправить тестовый ответ с телефона и убедиться, что строка появилась в таблице.

---

## Что важно знать

- **Репозиторий публичный.** Адрес и имена видны всем, у кого есть ссылка. Персональные данные (телефоны, номера карт) на страницу не выносить.
- **Ответы гостей.** Их видит только владелец таблицы, но защиты от накрутки нет: технически кто угодно может отправить произвольные строки. Для свадьбы это не проблема, для чего-то серьёзнее — нужна авторизация.
- **Музыка.** Браузеры блокируют автозапуск звука, поэтому включение только по кнопке — иначе никак.
- **Файл трека** держать в пределах 3–5 МБ, иначе на мобильном интернете страница будет грузиться долго.
- **Если запрос не проходит из-за CORS** — замена одной строки в `sendRsvp` (`app.js`): добавить `mode: 'no-cors'` и убрать чтение ответа. Данные будут записываться, но подтвердить успех сайт уже не сможет, поэтому это запасной вариант.

## Свой домен (необязательно, платно)

Домен в зоне `.kg` — примерно 10–20 $ в год. Настраивается в **Settings → Pages → Custom domain**, сертификат GitHub выпустит бесплатно.
